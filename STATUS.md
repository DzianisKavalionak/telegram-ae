# Готовность шаблона

Обновлено 3 ноября 2026 года.

## Согласовано

- Исходник — PNG ленты на зелёном фоне, включающий карточку профиля.
- Зелёная подложка удаляется через Keylight.
- Лента и профиль разделяются для независимого размещения в 3D.
- В проект добавляются настоящая 3D-камера и анимация её движения.
- Выбранный пользователем текст выделяется построчно.
- Предоставленный постоянный фон используется автоматически в каждой графике.
- Правила и общая основа хранятся в DzianisKavalionak/telegram-ae для передачи другому человеку.
- Любые изменения общих принципов и общего JSX автоматически сохраняются в GitHub в ходе текущей задачи, без повторного напоминания.
- С первого кадра вся сцена слегка размыта Camera Lens Blur, который плавно уходит в 0 к концу прокрутки.
- Постоянный фон — вращающийся 3D-слой с увеличением для закрытия углов кадра.

## Подготовлено

- Правила для ассистента и инструкция запуска по ссылке.
- Описание изученного видеореференса.
- Общий JSX, читающий отдельную конфигурацию shot.jsxinc.
- Пример структуры разметки исходного PNG.
- Оригинальный общий PNG-фон в template/assets/telegram_background.png.
- Механизм Keylight, защиты внутренних цветов, выделений, прокрутки и 3D-камеры.

## Первая конкретная сборка

Подготовлен первый локальный пакет по новому скриншоту и заданной пользователем фразе: JSX, измеренная конфигурация, оригинальный скриншот, постоянный фон и инструкция. Частные материалы конкретной сборки остаются в локальной выдаче.

Пользователь запустил пакет V1 и сообщил об остановке на строке 242: TypeError: null is not an object. Причина — неверное внутреннее имя точки наведения камеры. Исправление перенесено в общий сборщик; добавлены проверяемые обращения к свойствам камеры и запись COMPATIBILITY.md. Подготовлен пакет V2.

После отзыва пользователя «В принципе норм» на V2 подготовлена V3: общий Camera Lens Blur 4 px с плавным снятием к концу прокрутки и отдельный вращающийся 3D-фон с компенсацией глубины и запасом масштаба 25%.

V3, JSX-тесты и рендер агентом не запускались. Полная сборка, качество ключа и покрытие углов при движении требуют просмотра в AE. Подготовка исходников не означает фактического исполнения.

Дальнейшие согласованные изменения процесса следует переносить в правила и общий сборщик, чтобы репозиторий оставался самостоятельным источником для нового пользователя.
